# Pelotões de companheiros

- Hologramas agrupados usam o mesmo tamanho de uma unidade isolada, tanto no desktop quanto no celular.
- A quantidade de fileiras não reduz o tamanho das unidades.
- As posições ficam próximas e as fileiras se sobrepõem parcialmente para dar profundidade ao pelotão.
- A quantidade de colunas se adapta ao espaço da fileira; o campo reserva a altura necessária.
- As cartas abertas pelo botão de quantidade também ficam mais próximas, com pequena sobreposição.
- O botão de quantidade fica centralizado e possui espaço abaixo do grupo.

Alteração visual compartilhada pelos modos de combate. Não modifica poder, bônus, fileiras lógicas ou regras de companheiros. Não exige migração SQL.

Apresentação renderizada localmente no desktop e no celular. Arquivos e ZIP atualizados; o site online ainda precisa receber a publicação.
