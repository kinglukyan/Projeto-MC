# Símbolos e apresentação das cartas

- Novos emblemas para Grécia, Nórdicos, Egípcios, Celtas, Alyns e Monstros.
- Símbolos atualizados nas boas-vindas, no hall e no cadastro de emblemas do editor administrativo.
- 38 artes de personagens do catálogo produzidas com o renderizador do TCG, com natureza, temas de facção e alinhamento do número de poder.
- As artes estão em `assets/cards-v3`; os dados do aplicativo apontam para essas versões após a composição do catálogo.
- Os hologramas, os identificadores das cartas e suas regras não são alterados.
- O manifesto de mídia e as revisões dos scripts foram atualizados para o cache receber os arquivos novos.

Esta pasta é a entrega para publicação. Não há sessão de publicação do Vercel configurada neste ambiente; atualizar os arquivos não publica automaticamente o domínio.
